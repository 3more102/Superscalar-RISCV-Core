# Security Policy

This repository is an **educational/research processor RTL project**. It is not security-certified, silicon-proven, or intended to be treated as a hardened production CPU.

If you identify a security-relevant design or tooling issue, prefer GitHub's private vulnerability reporting mechanism when it is enabled for the repository. Otherwise, open a minimal public issue only when disclosure would not create unnecessary risk.

Please include:

- affected module/file
- architectural impact
- reproduction conditions or test program
- whether the issue affects architectural state, isolation, or tooling/CI integrity

Do not include credentials, private keys, access tokens, proprietary PDK files, or confidential EDA data in reports.
