# Directed assembly intent

The `.hex` tests are generated by `scripts/gen_directed_tests.py` using the controlled RV32IM encoder because the current execution environment does not provide a RISC-V GCC toolchain.  The generated tests correspond to the requested conceptual assembly groups:

1. `01_alu` — integer ALU and edge values
2. `02_dual_issue` — independent ALU pairs
3. `03_dependencies` — RAW dependency chain
4. `04_forwarding` — consecutive producer/consumer operations
5. `05_branches` — taken and not-taken conditional branches
6. `06_jumps` — JAL/JALR link/redirect
7. `07_load_store` — byte/half/word sign and zero extension
8. `08_mul` — MUL/MULH/MULHSU/MULHU
9. `09_div` — signed/unsigned DIV/REM plus divide-by-zero and overflow
10. `10_random_mix` — mixed ALU/memory/M extension sequence
11. `11_stress_dependencies` — long RAW chain
12. `12_branch_flush` — loop and wrong-path suppression case

The generator is the source of truth so instruction encodings are reproducible.
